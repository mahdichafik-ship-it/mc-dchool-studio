---
name: Client-requested roster fields
description: User-approved scope for optional client-specific student fields.
---

Optional client-requested fields should be selected and mapped during roster import, then stored per student and shown in student details only. They must not be added to roster-table columns, QR codes, or QR cards unless the user changes this requirement.

**Why:** The user specified that fields are optional, decided at import, and visible on student details only; they explicitly asked to keep QR views unchanged.

**How to apply:** Keep the import mapping, durable storage, and student-details editing/display path aligned. Check that QR generation and roster table layouts do not expose these fields.
