---
name: Stripe sandbox claiming
description: Stripe Dashboard onboarding required before using the Replit-connected development sandbox.
---

The Replit Stripe connection can report healthy and allow API access while Stripe Dashboard still shows “Claim your sandbox.” The development sandbox must be claimed through the Stripe Dashboard before treating dashboard access as complete.

**Why:** Stripe separates the Replit-managed development connection from ownership of the sandbox account. The app can authenticate and access test-mode products before the dashboard account is claimed.

**How to apply:** In Stripe Dashboard, select the existing business or create a new account, then choose Continue. Do not request or paste API keys into chat; the Replit connection remains the credential source.
