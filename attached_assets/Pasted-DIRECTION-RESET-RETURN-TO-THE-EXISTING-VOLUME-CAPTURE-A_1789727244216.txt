==================================================
THE ORIGINAL REQUIREMENT
==================================================

The photographer has an existing project on the desktop.

Example:

Project
├── Class 1A
├── Class 1B
└── Class 2A

The photographer discovers another real class on location.

They click:

+ Add Class

and create:

Class 2B

The project then simply becomes:

Project
├── Class 1A
├── Class 1B
├── Class 2A
└── Class 2B

Class 2B is now a NORMAL class in that project.

For corporate projects the exact same principle applies using
Group/Department terminology.

==================================================
IT MUST WORK ONLINE AND OFFLINE
==================================================

The photographer must be able to do this whether internet connectivity
exists or not.

The photographer must then be able to:

- see the new Class/Group
- add a missing person
- move an existing person into it
- select that person
- photograph normally
- restart the application and still see it
- see it in the normal project folders
- see its photographs with the project
- include it when the project/photos are uploaded

There must not be a special temporary/recovery/offline Class type.
